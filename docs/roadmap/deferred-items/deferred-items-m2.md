## 使用约定

- **状态**：`待回补` / `已回补（附 spec/commit 引用）` / `裁定不做（附理由）`。
  条目回补完成后：本文件改状态并附引用，同时从总入口的「未完成条目」表移除。
- 上游侵入点编号（I1–I12）沿用原报告 §3 侵入点总表；凡涉及上游仓库改动，
  **必须事先人工批准**（宪法原则 I）。
- F 编号全局唯一、跨里程碑递增（接续 M1 的 F13）。

## 与里程碑的对应速查

- **F14/F15/F16 均不绑死里程碑**：回补时点 = 上游 I5/I2/I1 合并发版 +
  moonhttp 钉版升级，随后在任一在途里程碑顺路兑现（改动面小、互不阻塞）；
  每次里程碑拆分时照例核对本表。
- **上游 PR 状态**：三份材料在 M2-P07 产出；提交与否取决于人工批准
  （宪法原则 I），被拒/搁置时本三条转「裁定不做」或维持待回补并注明。
